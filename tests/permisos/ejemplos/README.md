# Ejemplos del registro de rutas (solo pruebas)

Carpeta `app` de mentira que usa `tests/permisos/registro-rutas.test.ts` para comprobar que el
revisor del registro **falla** cuando una ruta de `/api/admin` no declara permiso. No es parte de
la aplicación: Next.js solo sirve la carpeta `app/` de la raíz del repositorio.
